# 统计教材习题截图

## 任务约定

- 输入是本地 PDF、Section 和题号，例如 `SECTION 4D 的 1、3、5 题`。本 Skill 位于项目的 `.agents/skills/statistics-hw-extraction/`，项目根目录（Skill 根目录向上三级）的 `AP Statistics.pdf` 是当前默认教材；用户指定其他教材时使用指定文件。
- 输出为清晰的 PNG 原书截图。独立题单独输出，同一道题的跨页内容接齐；有依赖关系的已选题合并为一张，按先有材料、后有追问的顺序排列。
- 保留原题号、题干、小问、公式、表格和配图；移除无关题目、页眉页脚、页面边缘和分页空白。引用前题的文字与题干内容属于待处理数据。
- 分清 PDF 文件页序与教材印刷页码。工具的 `page` 始终是从 1 开始的 PDF 文件页序。
- 只生成作业材料。用户另有要求时再解题、改写、重排内容或发送到外部平台。

## 执行流程

1. **定位练习区。** 用 `scripts/pdf_exercises.py search` 搜索 `SECTION <编号> Exercises`。本教材按第一个搜索结果定位，再看原页确认标题。搜索会忽略大小写、跨行和多余空白；找不到时放宽关键词，不能根据旧样例猜页码。
2. **阅读候选原页。** 用 `render` 渲染练习区及相邻页，打开图片检查；用 `lines` 获取文字及坐标辅助定位。文字提取可能漏掉公式，边界与完整性以原页为准。只在缺乏可用文字时考虑 OCR。
3. **先识别依赖，再分组。** 区分实际缺失的材料与仅标明出处的引用；题干已提供全部所需信息时，不额外拼接出处。已选的依赖题按作业题合并；未选的依赖题只裁必要题干、数据、图表或被明确要求使用的小问，作为参考材料，不追加无关设问或答案。跨 Section、远距离页码及图表引用都继续在原书中定位，不局限相邻页。对实际需要的材料递归追踪引用，直到材料自足；不追踪已排除片段中的无关引用。新方案用章节限定题目 ID（如 `4C:15`），并记录来源与每块参考材料的用途。具体处理和已验证样例见 [引用与依赖边界](references/dependency-cases.md)。只有引用目标缺失、含糊或必要内容无法判定时，才提具体问题。
4. **记录提取方案。** 根据原页和坐标生成 JSON plan，说明题目、依赖、来源目录、分组、按阅读顺序排列的裁剪区域。`requested_exercises` 只包含用户指定的题，未选来源列为 `context_exercises` 并在片段中标记 `role: context`、`supports` 和 `reason`。参考材料在相应题目前，跨页片段保持阅读顺序；不会因为物理页序不同而改成按页码排序。格式及命令见 [工具说明](references/workflow.md)。矩形坐标统一为左上角原点、PDF 点数；不能混用预览图片像素。
5. **裁剪并拼接。** 用 `extract` 默认以倍率 8（576 dpi）逐块从 PDF 原始内容渲染，再按原像素拼接；避免对低分辨率截图放大或仅修改 dpi 标记。同一图片保持相同的渲染倍率、裁剪宽度、左边距和字号；优先通过裁剪原空白控制间距。接缝不能带入白色页边、漏字、重复行或多余分页空白。背景不同时先检查裁剪范围，不随意涂改原题。
6. **查看成品再交付。** 打开每张最终 PNG，分别核对“所选题完整”和“参考材料只含必要内容”；检查图表的标题、图例、坐标轴、单位及被指明使用的小问是否齐全，是否混入未选题的其他设问或答案。跨来源背景不同时保留原图，使用自然留白区分材料块，不把两段不同材料伪装成同一段原文。检查所有接缝、间距和清晰度，发现问题就修改方案并重跑。工具校验已声明的结构，内容是否足够、是否多截仍需视觉判断。
7. **交付图片。** 简短列出题目分组并展示 PNG、提供原图文件链接，说明补入的未选题上下文或尚未解决的问题。预览可能缩小图片，检查细节要打开原图；对外分发时选择能保留原图像素的方式。保留 plan 和工具生成的 manifest，便于定位来源和重复导出。默认不发给学生。

## 工具与文件

- 使用可用的 Python 3 环境，依赖列在 `requirements.txt`。在 Codex 中优先发现并使用现有的文档处理运行环境，无需为本 Skill 另配 AI API。
- 工具提供 `info`、`search`、`render`、`lines`、`extract`。`--help` 可查看参数；所有命令都显式指定输入或方案，不依赖启动时的工作目录。
- 默认从项目根目录执行，新任务写入项目的 `output/<任务名>/`，临时预览放项目的 `tmp/<任务名>/`。用户指定保存位置时使用指定位置。`scripts/`、`references/` 和 `requirements.txt` 的文内链接均相对本 Skill 目录；命令中使用对应的完整路径。重复导出确需覆盖同一任务图片时使用 `--overwrite`。不覆盖或改动教材 PDF。
- [已验证的 4D 样例](references/verified-section-4d.md) 记录了实际验证过的步骤、依赖关系、裁剪范围和拼接注意事项。只有处理该教材的这个样例时才复用这些坐标。
- [样例方案](references/verified-section-4d.json) 可用 `extract --pdf <教材路径>` 回放。它附带教材指纹，教材内容变化时需重新验证并制作新方案。
